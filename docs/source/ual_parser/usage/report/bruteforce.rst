Password-guessing / Bruteforce
==============================

This is a classic attack scenario. For a user to be flagged, multiple failed login attempts within a given period (say 2 hours) has to be recorded followed by a successful login from the same IP. Not much screenshot to show here but interestingly enough, this user has recorded 36 failed login attempts within an hour followed by a successful login. Whether or not that will prove a successful password guessing is something that needs to be correlated with other indicators. An experienced investigator will surely flag this one as such.

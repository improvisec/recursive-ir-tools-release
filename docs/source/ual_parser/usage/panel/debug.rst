Debug Window
============

The debug window mainly act as an input prompt when searching for operations, users, or indicators. It also prints out various messages during the user's interaction with the application.

To move out of this panel, tab (to users panel) or shift+tab (to operations panel) can be used. The input prompt changes depending on which panel is in focus. [Search oerations], [Search users/apps], and [Search IOCs].

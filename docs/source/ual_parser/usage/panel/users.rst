Users and Applications
======================

This panel contains all matching users and applications or service principals according to whichever operations or indicators were enabled. Each user or app also has a corresponding checkbox/toggle where then can be further filtered before generating the xlsx report or exporting their events into json. Every user will also have the corresponding matching operations count on the left as well as the number of events on the right enclosed in parenthesis.

To quickly find out what operations matched a given user or application, deselect all users by pressing 'Esc' and toggle an individual user again. All matching operations for a user will be displayed in the debug window.

When this panel is in focus, a > cursor will also be visible. A user search prompt is also displayed in the debug panel so text can be entered at any time.

Searching Users
--------------------

Users can be searched to further narrow down the list. Text can be typed at any time while the users panel is in focus. The list is dynamically updated likewise as soon as you start typing. The cursor also moves into position automatically to the first matching user. 

.. image:: /images/search_user1.png
   :alt: log path
   :scale: 50


Similar to when searching for operations, navigate through the resulting list using left and right arrow keys if it occupies more than one page. The count of matching users and selected users including the page count and the current page are also displayed at the bottom. Make sure to check selected users count before hitting the report/export buttons at the bottom. Press 'Esc' at anytime to clear all selections.

Text UI
=======

The text UI of Unified Audit Log Investigator application is divided into three panels, the main ones being the operations panel and the users and applications panel. There is also a debug window panel where various information are written and also serves as a text input control. 

Users can navigate through the whole application using only their keyboard. A help menu is also provided which contains all available commands. 

This section covers the different application panels that can be found in UAL Investigator.
